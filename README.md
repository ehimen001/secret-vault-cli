# 🔐 Secret Vault CLI

A simple command-line vault application built with Python using object-oriented programming (OOP).

This app allows users to:
- Create a secure vault
- Store vault accounts in memory
- Access vaults using password verification

---

## 🚀 Features

- 🔑 Password-protected vaults
- 👤 Multiple user vault support
- 🧠 Built using OOP principles (encapsulation, classes)
- 💻 Interactive command-line interface

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

---

## 📦 How It Works

1. Create a vault account
2. Set a password (minimum 8 characters)
3. Access the vault by entering the correct password

---

## ▶️ Usage

Run the script:

python vault.py
